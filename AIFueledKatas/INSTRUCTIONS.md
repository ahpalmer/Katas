This folder is for morning katas, and the intention is to use AI during these specific Katas.
The idea is to create more complex programs than a hand-written kata will allow
Look at ProblemSets for the next problem to work on.
This will allow you to learn more about software architecture
The goal is to move up the software stack from writing individual lines of code up to larger code modules
For example, the first problem in ProblemSets is to implement jitter and exponential backoff in http responses to prevent thundering herd retries when accessing a server
This would normally be too large of a problem for a morning kata. With the help of AI it is much easier to create the individual parts of the http request and response, which allows me to practice making these modules more efficient. This will be a more valuable skill in the AI era than writing individual methods
